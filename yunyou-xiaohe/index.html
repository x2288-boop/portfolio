01 / PROJECT CONCEPT
PROJECT

项目概念

为什么做云游小河？它连接「人 × 风景 × 情绪」，为文旅场景打造一个可被识别、被喜爱、可落地的治愈系数字 IP。

← 首页/项目概念
项目名称
云游小河
项目定位
数字文旅 IP
云端旅行小精灵 · 以「旅行探索」为核心的数字 IP 形象。
探索陪伴指引记录
核心概念
连接 人 × 风景 × 情绪
云游小河把每一次出发都变成一段有温度的记录。它不只是向导，更是旅伴——在路途中的好奇、惊喜与安心，都由它认真珍藏。
设计目标
为文旅场景打造一个可被识别、可被喜爱、可被落地的治愈系 IP 形象；用清晰的人格与世界观，让游客与风景之间产生更亲密的情感联结，并延伸到游客中心、导览、文创与数字导览等真实触点。
STRATEGY

五大设计策略

1

IP 人格化

赋予小河鲜明的性格、语言与动作，让形象可被记住、可被对话。

2

场景世界观

搭建云端驿站与目的地体系，让 IP 拥有可探索的空间与故事。

3

情绪资产

将旅途情绪沉淀为可复用资产，让每次互动都有情感共鸣。

4

互动体验

以指路、抽签、写信等轻互动，建立用户与 IP 的长期关系。

5

文旅落地

从游客中心到 AI 导览，把 IP 转化为可部署的视觉与体验系统。

IP 设定

云端旅行小精灵 · 头顶指南针、身披山河斗篷。从角色、视觉、情绪到动作，形成一套完整的 IP 资产系统。

一个诞生于云端的旅行小精灵。它的云朵发型柔软蓬松，头顶悬浮着一枚金色指南针，身披山河青绿的斗篷，背上挎着装满地图和车票的旅行小包——每一段旅程，都是它认真记录的故事。

指南针 · 永远指路

头顶的指南针是小河的核心标识，象征它为旅人指引方向的使命——无论走到哪里，都不会迷路。

斗篷 · 山河之色

青绿色的斗篷取自山川湖泊的色调，代表着小河与自然风景之间的深厚联结。

旅行包 · 装满故事

背上的小包装着地图、车票和沿途收集的风景，是小河作为"旅行记录者"的身份象征。

角色形象

头顶悬浮金色指南针、身披山河青绿斗篷、云朵发型柔软蓬松的旅行小精灵，整体造型治愈、轻盈、现代。

角色性格

认真、好奇、温柔。不是冷冰冰的向导，而是有温度的旅伴——指路时专注，发现风景时惊喜，分别时温暖。

核心符号

指南针、山河斗篷、旅行小包是小河的三组核心视觉符号，贯穿角色、场景与应用，形成统一识别。

旅行装备

背上挎着装满地图与车票的旅行小包，沿途收集的风景都被认真收藏——这是"旅行记录者"身份的最佳注脚。
